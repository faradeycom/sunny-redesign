# Sunny — два нові дизайни сайту

Концепти редизайну [sunny-tm.com](https://sunny-tm.com/uk) у світлих сонячних тонах.

- `/a/` — дизайн А «Ранок»
- `/b/` — дизайн Б «Полудень»

Сторінки генеруються скриптом `python build.py` з даних у `content.py` і `shops.json`.
Стилі — `a/style.css`, `b/style.css`; спільна логіка — `app.js`. Форми працюють у демо-режимі.
